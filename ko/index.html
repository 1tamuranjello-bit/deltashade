Mac & Windows

Windows에는 화면 색을 Lab으로 보는 기본 도구가 없습니다

Mac에는 ‘디지털 색상 측정기’가 처음부터 들어 있지만, Windows에는 이에 해당하는 기본 도구가 없습니다. DeltaShade는 Mac에서도 Windows에서도 같은 화면, 같은 키 조작으로 쓸 수 있습니다.

Mac

디지털 색상 측정기를 비교를 위한 도구로

수치를 구하는 방식은 디지털 색상 측정기와 같으며, 커서 옆 상시 표시·기준점과의 ΔE·비교점 기록을 더했습니다.

Windows

Windows에서도 같은 조작으로 Lab과 ΔE를

Shift 두 번으로 기준점, Ctrl 두 번으로 비교점. Mac 버전과 같은 화면, 같은 조작으로 쓸 수 있습니다. 디스플레이의 색상 프로파일을 읽어 Lab을 계산합니다.

Install

처음 열 때의 절차

DeltaShade는 개인이 개발한 앱으로, Apple이나 Microsoft의 유료 개발자 등록을 하지 않았습니다. 그래서 처음 한 번만 확인 화면에서 다음 조작이 필요합니다.

Mac

  1. 다운로드한 dmg를 열고 DeltaShade를 ‘응용 프로그램’ 폴더로 드래그합니다.
  2. DeltaShade를 더블 클릭합니다. 열 수 없다는 확인 창이 나오면 ‘완료’를 누릅니다.
  3. ‘시스템 설정’ → ‘개인정보 보호 및 보안’을 열고 아래쪽의 DeltaShade 옆 ‘그래도 열기’를 누릅니다.
  4. 안내에 따라 ‘화면 기록’과 ‘손쉬운 사용’을 허용합니다.
  5. 메뉴 막대의 ΔE 아이콘을 열고 이메일로 받은 라이선스 키를 입력합니다.

Windows

  1. 다운로드한 DeltaShade-Setup.exe를 더블 클릭합니다.
  2. ‘Windows의 PC 보호’가 나오면 ‘추가 정보’ → ‘실행’을 누릅니다.
  3. 화면 안내에 따라 설치합니다. 관리자 권한은 필요하지 않습니다.
  4. 알림 영역의 ΔE 아이콘을 열고 이메일로 받은 라이선스 키를 입력합니다.

FAQ

자주 묻는 질문

화면 기록과 손쉬운 사용 권한은 어디에 쓰나요?

화면 기록은 커서 위치의 색을 읽기 위해, 손쉬운 사용은 Shift·Control 두 번 누르기를 감지하기 위해 사용합니다. 화면 이미지를 저장하거나 외부로 보내는 일은 없습니다.

‘Apple은 확인할 수 없습니다’ ‘Windows의 PC 보호’가 표시됩니다. 안전한가요?

Apple이나 Microsoft의 유료 개발자 등록을 하지 않은 개인 개발 앱에서는 이 표시가 나옵니다. 위의 ‘처음 열 때의 절차’대로 한 번만 허용하면 이후에는 평소처럼 실행됩니다.

모니터의 색상 프로파일을 바꾸면 수치가 달라지나요?

디지털 색상 측정기와 마찬가지로 표시에 사용하는 프로파일로 역산하므로 대부분 달라지지 않습니다. 디스플레이가 표현할 수 없는 아주 선명한 색만 달라질 수 있습니다.

구강 내 실제 색을 측정할 수 있나요?

아니요. DeltaShade가 보여 주는 것은 사진에 기록된 색입니다. 측색계를 대신하거나 진단 목적으로 사용할 수 없습니다. 촬영 조건을 맞춘 사진끼리 비교하는 데 사용하세요.

Intel Mac에서 쓸 수 있나요?

쓸 수 없습니다. M1 이후의 Apple 실리콘을 탑재한 Mac이 대상입니다.

Mac과 Windows에서 수치가 같나요?

둘 다 같은 식으로 계산하지만 화면 색을 다루는 방식이 OS마다 달라 완전히 같지는 않습니다. 개발 중 확인에서는 같은 색 견본으로 약 0.7 이내의 차이였습니다. 비교는 항상 같은 컴퓨터에서 하세요.
