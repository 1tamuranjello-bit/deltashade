Always in front

写真をクリックしても、数値は隠れない

デジタルカラーメーターは普通のウィンドウなので、写真のウィンドウをクリックすると後ろに隠れてしまいます。DeltaShade の数値は、いつもカーソルのすぐ横、一番手前に出ています。

デジタルカラーメーター
  • 数値は画面の隅の別ウィンドウに出る
  • 写真を拡大・移動しようとクリックすると、後ろに隠れる
  • 数値を見るたびに、ウィンドウを探して前に出し直す
DeltaShade
  • 数値はカーソルのすぐ横に出る。視線を動かさずに読める
  • 写真をクリックしても、常に一番手前に表示されたまま
  • 比較ウィンドウも手前に浮かび続けるので、作業の手が止まらない

Features

シェード比較に必要なことだけ

いつもの画像ビューアの操作を邪魔せず、横で見張るだけの小さな道具です。

L* a* b*

カーソル横に常時表示

カーソルの下の色を 1 秒に約 15 回読み取り、色見本と L・a・b をカーソルのすぐ横に表示します。

ΔE00 / ΔE94 / ΔE76

基準点との色差

基準点を決めると、カーソル位置との ΔE をその場で計算。標準は CIEDE2000、設定で CIE94・CIE76 にも切り替えられます。

11 × 11 pt

デジタルカラーメーターと同じ絞り

絞りサイズは 1〜11 の 6 段階（初期値は最大）。macOS 標準のデジタルカラーメーターと同じ範囲を、同じ手順で平均します。

基準と現在を、隣り合わせで

比較ウィンドウには基準点と今のカーソル位置の色が左右に並び、L・a・b それぞれの差分と ΔE が一目でわかります。

比較点を 5 つまで記録

気になる箇所を保存しておけば、メニューバーの一覧で時刻・色見本・Lab・基準点からの ΔE をあとから見返せます。

クリックを横取りしない

操作はすべてキーの 2 度押し。プレビューや Photoshop のクリックや右クリックメニューには影響しません。

Mac & Windows

Windows には、画面の色を Lab で見る標準ツールがありません

Mac には「デジタルカラーメーター」が最初から入っていますが、Windows にはそれにあたる標準ツールがありません。DeltaShade は Mac でも Windows でも、同じ画面・同じキー操作で使えるように作っています。

Mac

デジタルカラーメーターを、比較のための道具に

数値の出し方はデジタルカラーメーターと同じまま、カーソル横の常時表示・基準点との ΔE・比較点の記録を加えました。

Windows

Windows でも、同じ操作で Lab と ΔE を

Shift 2度押しで基準点、Ctrl 2度押しで比較点。Mac 版と同じ画面・同じ操作で使えます。ディスプレイのカラープロファイルを読んで Lab を計算します。

Install

はじめて開くときの手順

DeltaShade は個人開発のため、Apple や Microsoft の有料の配布者登録をしていません。そのため初回だけ、確認画面で次の操作が必要です。

Mac

  1. ダウンロードした dmg を開き、DeltaShade を「アプリケーション」フォルダにドラッグします。
  2. DeltaShade をダブルクリックします。「開けません」という確認が出たら「完了」を押します。
  3. 「システム設定」→「プライバシーとセキュリティ」を開き、下の方にある「DeltaShade」の「このまま開く」を押します。
  4. 案内に従って「画面収録」と「アクセシビリティ」を許可します。
  5. メニューバーの ΔE のアイコンを開き、メールで届いたライセンスキーを入力します。

Windows

  1. ダウンロードした DeltaShade-Setup.exe をダブルクリックします。
  2. 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押します。
  3. 画面の案内に従ってインストールします。管理者の許可は必要ありません。
  4. 通知領域の ΔE のアイコンを開き、メールで届いたライセンスキーを入力します。

FAQ

よくある質問

画面収録とアクセシビリティの許可は何に使いますか？

画面収録はカーソル位置の色を読み取るため、アクセシビリティは Shift・Control の 2 度押しを見張るために使います。画面の画像を保存したり、外部に送信したりすることはありません。

「開発元を確認できません」「PC が保護されました」と出ます。安全ですか？

Apple や Microsoft の有料の配布者登録をしていない個人開発のアプリでは、この表示が出ます。上の「はじめて開くときの手順」のとおり、一度だけ許可すれば以降は普通に起動できます。

モニターのカラープロファイルを変えると数値は変わりますか？

デジタルカラーメーターと同じく、表示に使っているプロファイルで逆算するため、ほとんどの場合は変わりません。ディスプレイで表示しきれない鮮やかな色だけは変わることがあります。

口腔内の実際の色を測定できますか？

いいえ。DeltaShade が示すのは写真に記録された色です。測色計の代わりや診断の目的には使えません。撮影条件をそろえた写真どうしの比較にお使いください。

Intel の Mac で使えますか？

使えません。M1 以降の Apple シリコンを搭載した Mac が対象です。

Mac と Windows で数値は同じになりますか？

どちらも同じ式で計算しますが、画面の色の仕組みが OS ごとに違うため、まったく同じにはなりません。開発時の確認では、同じ色見本で小数第 1 位で 0.7 程度以内の差でした。比較はいつも同じパソコンで行ってください。
