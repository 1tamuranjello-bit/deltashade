Install guide

ダウンロードから使い始めるまで

ご購入後、DeltaShade をダウンロードしてインストールし、使い始めるまでの手順を、画面に出る言葉どおりにご案内します。パソコンに詳しくない方も、上から順に進めれば大丈夫です。

まず、購入後に届くメールを開きます

ご購入が終わると、「Owl Dental Create」から購入確認のメールが届きます（英語の表記が混ざることがあります）。このメールに、次の 2 つが入っています。

  • ダウンロードのボタン：Mac 用（DeltaShade-○○.dmg）と Windows 用（DeltaShade-Setup.exe）の 2 つ。お使いのパソコンに合うほうだけで大丈夫です。
  • ライセンスキー：「1A2B3C4D-…」のような英数字の長い列です。アプリを使えるようにするときに入力します。

メールが見当たらないときは、迷惑メールのフォルダもご確認ください。それでも見つからない場合は、Lemon Squeezy の「My Orders」で購入時のメールアドレスを入力すると、ダウンロードとライセンスキーをもう一度確認できます。

Mac の手順へ Windows の手順へ

Mac の場合

M1 以降の Apple シリコンを搭載した Mac と、macOS 26 以降が必要です。

  1. ダウンロードする

    メールの中の Mac 用のダウンロードボタン（.dmg のファイル）を押します。ファイルは「ダウンロード」フォルダに保存されます。Safari の場合は、右上の ↓ のボタンからも開けます。

  2. 「アプリケーション」フォルダに入れる

    ダウンロードした dmg をダブルクリックすると、DeltaShade のアイコンと「Applications」フォルダが並んだ窓が開きます。DeltaShade のアイコンを「Applications」フォルダの上までドラッグしてください。終わったら、Finder の左側に出ている「DeltaShade」の横の ⏏（取り出し）を押して閉じます。

  3. 初めて開く（確認が出ます）

    Finder の「アプリケーション」フォルダで DeltaShade をダブルクリックします。「“DeltaShade”は開かれませんでした」という確認が出たら、「完了」を押してください（「ゴミ箱に入れる」は押さないでください）。Apple の有料の配布者登録をしていない個人開発のアプリで出る確認で、故障ではありません。

  4. 「このまま開く」を押す

    画面左上の Apple マーク →「システム設定」→ 左の一覧の「プライバシーとセキュリティ」を開きます。右側を下の方までスクロールすると「“DeltaShade”は Mac を保護するためにブロックされました」と出ているので、「このまま開く」を押します。もう一度確認が出たら「このまま開く」を押し、Mac のログインパスワード（または Touch ID）で許可します。この操作は最初の 1 回だけです。

  5. 2 つの許可をオンにする

    DeltaShade が開くと「DeltaShade の権限」という窓が出ます。「画面収録」と「アクセシビリティ」の「許可する…」を順に押し、開いたシステム設定の一覧で DeltaShade のスイッチをオンにします（画面収録は「画面収録とシステムオーディオ録音」という名前の項目です）。両方オンにしたら「DeltaShade を再起動」を押してください。

  6. ライセンスキーを入力する

    「DeltaShade のライセンス」という窓が開きます（開かないときは、画面右上のメニューバーにある ΔE のアイコン →「ライセンス…」）。メールのライセンスキーを選んで ⌘（command）+ C でコピーし、入力欄をクリックして ⌘ + V で貼り付け、「有効にする」を押します。インターネットにつながっている必要があります。

  7. 自動で起動するようにする（お好みで）

    ΔE のアイコン →「設定…」で「ログイン時に DeltaShade を起動」をオンにすると、Mac を起動するたびに DeltaShade が自動で立ち上がります。

  8. 使ってみる

    プレビューなどで口腔内写真を開き、カーソルを歯の上に置くと、カーソルのすぐ横に L・a・b が出ます。基準にしたい歯の上で Shift を 2 度押しし、比べたい歯へカーソルを動かすと ΔE が出ます。

Windows の場合

Windows 11（64 ビット）が必要です。管理者の権限は必要ありません。

  1. ダウンロードする

    メールの中の Windows 用のダウンロードボタン（DeltaShade-Setup.exe）を押します。Microsoft Edge で「一般的にダウンロードされていません」と出た場合は、その行の「…」→「保存」→「詳細表示」→「保持する」を押してください。新しいアプリで出ることがある表示です。

  2. インストーラーを開く

    エクスプローラーの「ダウンロード」フォルダにある DeltaShade-Setup.exe をダブルクリックします。

  3. 「詳細情報」→「実行」を押す

    青い画面で「Windows によって PC が保護されました」と出たら、文中の「詳細情報」を押し、下に出てくる「実行」を押します。Microsoft の有料の配布者登録をしていない個人開発のアプリで出る確認で、最初の 1 回だけです。

  4. インストールする

    最初に言語を選ぶ画面が出たら「日本語」を選んで「OK」。あとは「次へ」で進みます。「Windows の起動時に DeltaShade を起動する」にチェックを入れておくと、毎回自動で立ち上がります。「インストール」→「完了」を押すと DeltaShade が起動します。

  5. ライセンスキーを入力する

    「DeltaShade のライセンス」という窓が開きます。メールのライセンスキーを選んで Ctrl + C でコピーし、入力欄をクリックして Ctrl + V で貼り付け、「有効にする」を押します。インターネットにつながっている必要があります。

  6. ΔE のアイコンの場所

    DeltaShade は画面右下（時計の近く）の通知領域に、ΔE のアイコンとして入っています。見当たらないときは「^」（隠れているインジケーターを表示）を押してください。アイコンをタスクバーへドラッグしておくと、いつでも見えて便利です。

  7. 使ってみる

    フォトなどで口腔内写真を開き、カーソルを歯の上に置くと、カーソルのすぐ横に L・a・b が出ます。基準にしたい歯の上で Shift を 2 度押しし、比べたい歯へカーソルを動かすと ΔE が出ます。

困ったときは

「すでに 2 台で使われています」と出る

1 つのライセンスキーで使えるのは、Mac・Windows あわせて 2 台までです。使わなくなったパソコンで、ΔE のアイコン →「ライセンス…」→「このパソコンの登録を解除」を押すと、別のパソコンで使えるようになります。古いパソコンが壊れて解除できない場合は、下のメールアドレスまでご連絡ください。

購入のメールが届かない・なくしてしまった

迷惑メールのフォルダをご確認ください。Lemon Squeezy の「My Orders」で購入時のメールアドレスを入力すると、届いたメールのリンクから、ダウンロードとライセンスキーをもう一度確認できます。

Mac で数値が出ない

「画面収録」の許可がオフになっている可能性があります。ΔE のアイコン →「権限…」を開き、案内に従って許可してから DeltaShade を再起動してください。新しい版に入れ替えたあとは、システム設定で DeltaShade のスイッチをいったんオフにして、オンにし直す必要がある場合があります。

Windows で DeltaShade が見当たらない

スタートメニューで「DeltaShade」と入力すると起動できます。起動していても、アイコンが通知領域の「^」の中に隠れていることがあります。

アンインストール（削除）したい

先に ΔE のアイコン →「ライセンス…」→「このパソコンの登録を解除」を押しておくと、ライセンスを別のパソコンで使えます。Mac：「アプリケーション」フォルダの DeltaShade をゴミ箱に入れます。Windows：「設定」→「アプリ」→「インストールされているアプリ」で DeltaShade の「…」→「アンインストール」を押します。

解決しないときは、お気軽にお問い合わせください（日本語・英語）： support@deltashade.app
