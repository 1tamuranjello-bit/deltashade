Always in front

點按照片，數值也不會被遮住

「數碼測色計」是一般視窗，一點按照片視窗就會躲到後面。DeltaShade 的數值始終顯示在游標旁邊、所有視窗的最前面。

數碼測色計
  • 數值顯示在螢幕角落的另一個視窗裡
  • 為了縮放或移動照片而點按時，它會躲到後面
  • 每次看數值都要找到視窗並重新叫到前面
DeltaShade
  • 數值顯示在游標旁邊，不必移開視線
  • 即使點按照片，也始終顯示在最前面
  • 比較視窗也一直浮在前面，工作不會中斷

Features

只做比色真正需要的事

一個不干擾平常使用的看圖軟體、只在旁邊默默工作的小工具。

L* a* b*

始終顯示在游標旁

每秒約 15 次讀取游標下的顏色，並在游標旁邊顯示色塊和 L、a、b。

Mac & Windows

Mac 內建「數碼測色計」，而 Windows 沒有相應的內建工具。DeltaShade 在 Mac 和 Windows 上畫面相同、按鍵操作相同。

Mac

把數碼測色計變成比色工具

數值的測量方式與數碼測色計完全相同，並增加了游標旁常駐顯示、與基準點的 ΔE 以及比較點記錄。

Install

首次開啟時的步驟

DeltaShade 由個人開發，沒有加入 Apple 或 Microsoft 的付費開發者計畫。因此僅在首次開啟時，需要在確認畫面中進行以下操作。

Mac

  1. 打開下載的 dmg，把 DeltaShade 拖到「應用程式」檔案夾。
  2. 按兩下 DeltaShade。如果出現無法打開的提示，請按「完成」。
  3. 打開「系統設定」→「隱私權與安全性」，在下方 DeltaShade 旁按「強制打開」。
  4. 依照引導允許「螢幕錄製」和「輔助使用」。
  5. 打開選單列中的 ΔE 圖像，輸入電子郵件中的授權金鑰。

Windows

  1. 按兩下下載的 DeltaShade-Setup.exe。
  2. 如果出現「Windows 已保護您的電腦」，請按「其他資訊」→「仍要執行」。
  3. 依照畫面引導完成安裝，不需要系統管理員權限。
  4. 打開通知區域中的 ΔE 圖示，輸入電子郵件中的授權金鑰。

FAQ

常見問題

螢幕錄製和輔助使用權限用來做什麼？

螢幕錄製用於讀取游標位置的顏色，輔助使用用於偵測連按兩次 Shift、Control。不會儲存螢幕影像，也不會傳送到外部。

出現「Apple 無法驗證…」或「Windows 已保護您的電腦」，安全嗎？

未加入 Apple 或 Microsoft 付費開發者計畫的個人開發 App 會出現此提示。依照上方「首次開啟時的步驟」允許一次，之後即可正常啟動。

變更顯示器的色彩描述檔後，數值會變嗎？

與數碼測色計一樣，會透過顯示所用的描述檔反算，因此大多數情況下不會變。只有顯示器無法顯示的非常鮮豔的顏色可能會變。

能測量口腔內的實際顏色嗎？

不能。DeltaShade 顯示的是照片中記錄的顏色，不能取代測色儀，也不能用於診斷。請用於比較拍攝條件一致的照片。

能在 Intel Mac 上使用嗎？

不能。需要搭載 Apple 晶片（M1 及更新）的 Mac。

Mac 和 Windows 上的數值相同嗎？

兩者使用相同的公式計算，但各作業系統處理螢幕顏色的方式不同，因此不會完全相同。開發期間的測試中，同一色樣的差異約在 0.7 以內。請始終在同一台電腦上進行比較。
