Install guide

從下載到開始使用

依照螢幕上出現的原樣文字，說明購買後下載、安裝並開始使用 DeltaShade 的步驟。即使不太熟悉電腦，只要從上到下依序操作即可。

首先，打開購買後收到的電子郵件

購買完成後，你會收到來自「Owl Dental Create」的購買確認郵件（可能為英文）。郵件中包含以下兩項：

  • 下載按鈕：Mac 版（DeltaShade-….dmg）和 Windows 版（DeltaShade-Setup.exe）兩個。只需要下載適合你電腦的那一個。
  • 授權金鑰：類似「1A2B3C4D-…」的一長串英數字。啟用 App 時需要輸入。

找不到郵件時，請檢查垃圾郵件資料夾。如果仍然找不到，在 Lemon Squeezy 的「My Orders」中輸入購買時的電子郵件地址，即可再次查看下載和授權金鑰。

Mac 的步驟 Windows 的步驟

Mac

需要搭載 Apple 晶片（M1 及更新）的 Mac 和 macOS 26 或以上版本。

  1. 下載

    按一下郵件中的 Mac 版下載按鈕（.dmg 檔案）。檔案會儲存到「下載項目」檔案夾。使用 Safari 時，也可以從右上角的 ↓ 按鈕打開。

  2. 放入「應用程式」檔案夾

    按兩下下載的 dmg，會打開一個並排顯示 DeltaShade 圖像和「Applications」檔案夾的視窗。把 DeltaShade 圖像拖到「Applications」檔案夾上。完成後，按一下 Finder 左側側邊欄中「DeltaShade」旁的 ⏏（退出）將其關閉。

  3. 首次打開（會出現提示）

    在 Finder 的「應用程式」檔案夾中按兩下 DeltaShade。如果出現「DeltaShade」未打開的提示，請按「完成」（不要按「丟到垃圾桶」）。這是未加入 Apple 付費計畫的個人開發 App 都會出現的提示，並非故障。

  4. 按「強制打開」

    按一下螢幕左上角的蘋果選單 →「系統設定」→ 左側列表中的「隱私權與安全性」。在右側往下捲動，會看到「DeltaShade」已被阻擋以保護你的 Mac 的提示，按「強制打開」。如果再次詢問，按「強制打開」，並用 Mac 的登入密碼（或 Touch ID）允許。此操作只需進行一次。

  5. 打開兩項權限

    DeltaShade 打開後會出現「DeltaShade 權限」視窗。依序按「螢幕錄製」和「輔助使用」的「允許⋯」，在打開的系統設定列表中開啟 DeltaShade 的開關（螢幕錄製的項目名稱為「螢幕與系統錄音」）。兩項都開啟後，按「重新啟動 DeltaShade」。

  6. 輸入授權金鑰

    會打開「DeltaShade 授權」視窗（如未打開，請按螢幕右上角選單列中的 ΔE 圖像 →「授權⋯」）。選取郵件中的授權金鑰，按 ⌘（Command）+ C 拷貝，按一下輸入欄位後按 ⌘ + V 貼上，然後按「啟用」。需要連上網際網路。

  7. 設定自動啟動（可選）

    按一下 ΔE 圖像 →「設定⋯」，開啟「登入時開啟 DeltaShade」，之後每次啟動 Mac 時 DeltaShade 都會自動啟動。

  8. 試用

    用「預覽程式」等打開口內照片，把游標放在牙齒上，游標旁就會顯示 L、a、b。在作為基準的牙齒上連按兩次 Shift，再把游標移到要比較的牙齒上，就會顯示 ΔE。

Windows

需要 Windows 11（64 位元），不需要系統管理員權限。

  1. 下載

    按一下郵件中的 Windows 版下載按鈕（DeltaShade-Setup.exe）。如果 Microsoft Edge 提示該檔案「不常下載」，請按該行的「…」→「保留」→「顯示更多」→「仍要保留」。新的 App 可能會出現此提示。

  2. 打開安裝程式

    在檔案總管中打開「下載」資料夾，按兩下 DeltaShade-Setup.exe。

  3. 按「其他資訊」→「仍要執行」

    如果出現藍色的「Windows 已保護您的電腦」畫面，請按文中的「其他資訊」，再按下方出現的「仍要執行」。這是未加入 Microsoft 付費計畫的個人開發 App 會出現的提示，只在第一次出現。

  4. 安裝

    如果出現選擇語言的畫面，請選擇「English」並按「OK」（安裝程式只有英文和日文）。然後按「Next」繼續。勾選「Start DeltaShade when Windows starts」後，每次都會自動啟動。按「Install」→「Finish」後，DeltaShade 就會啟動。

  5. 輸入授權金鑰

    會打開「DeltaShade 授權」視窗。選取郵件中的授權金鑰，按 Ctrl + C 複製，按一下輸入欄位後按 Ctrl + V 貼上，然後按「啟用」。需要連上網際網路。

  6. ΔE 圖示在哪裡

    DeltaShade 以 ΔE 圖示的形式常駐在螢幕右下角（時鐘附近）的通知區域。如果看不到，請按「^」（顯示隱藏的圖示）。把圖示拖到工作列上，就能一直看到，十分方便。

  7. 試用

    用「相片」等打開口內照片，把游標放在牙齒上，游標旁就會顯示 L、a、b。在作為基準的牙齒上連按兩次 Shift，再把游標移到要比較的牙齒上，就會顯示 ΔE。

遇到問題時

提示「已在 2 台電腦上使用」

1 組授權金鑰最多可用於 Mac 和 Windows 合計 2 台電腦。在不再使用的電腦上按 ΔE 圖示 →「授權⋯」→「取消此電腦的啟用」，即可在其他電腦上使用。如果舊電腦已損壞無法取消，請寄信到下方地址聯絡我們。

沒有收到購買郵件，或是弄丟了

請檢查垃圾郵件資料夾。在 Lemon Squeezy 的「My Orders」中輸入購買時的電子郵件地址，透過收到的郵件中的連結即可再次查看下載和授權金鑰。

Mac 上不顯示數值

可能是「螢幕錄製」權限已關閉。請按 ΔE 圖像 →「權限⋯」，依照引導允許後重新啟動 DeltaShade。換成新版本後，可能需要在系統設定中把 DeltaShade 的開關關閉後再重新開啟。

在 Windows 上找不到 DeltaShade

在開始功能表中輸入「DeltaShade」即可啟動。即使正在執行，圖示也可能藏在通知區域的「^」裡。

想要解除安裝（刪除）

先按 ΔE 圖示 →「授權⋯」→「取消此電腦的啟用」，授權就能用在其他電腦上。Mac：把「應用程式」檔案夾中的 DeltaShade 丟到垃圾桶。Windows：在「設定」→「應用程式」→「已安裝的應用程式」中，按 DeltaShade 旁的「…」→「解除安裝」。

如果仍無法解決，歡迎與我們聯絡（英文或日文）： support@deltashade.app
