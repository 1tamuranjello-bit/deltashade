Install guide

从下载到开始使用

按照屏幕上出现的原样文字，介绍购买后下载、安装并开始使用 DeltaShade 的步骤。即使不太熟悉电脑，只要从上到下依次操作即可。

首先，打开购买后收到的邮件

购买完成后，你会收到来自“Owl Dental Create”的购买确认邮件（可能为英文）。邮件中包含以下两项：

  • 下载按钮：Mac 版（DeltaShade-….dmg）和 Windows 版（DeltaShade-Setup.exe）两个。只需下载适合你电脑的那一个。
  • 许可证密钥：类似“1A2B3C4D-…”的一长串字母和数字。激活应用时需要输入。

找不到邮件时，请检查垃圾邮件文件夹。如果仍然找不到，在 Lemon Squeezy 的“My Orders”中输入购买时的邮箱地址，即可再次查看下载和许可证密钥。

Mac 的步骤 Windows 的步骤

Mac

需要搭载 Apple 芯片（M1 及更新）的 Mac 和 macOS 26 或更高版本。

  1. 下载

    点按邮件中的 Mac 版下载按钮（.dmg 文件）。文件会保存到“下载”文件夹。使用 Safari 时，也可以从右上角的 ↓ 按钮打开。

  2. 放入“应用程序”文件夹

    连按下载的 dmg，会打开一个并排显示 DeltaShade 图标和“Applications”文件夹的窗口。把 DeltaShade 图标拖到“Applications”文件夹上。完成后，点按访达左侧边栏中“DeltaShade”旁的 ⏏（推出）将其关闭。

  3. 首次打开（会出现提示）

    在访达的“应用程序”文件夹中连按 DeltaShade。如果出现未打开“DeltaShade”的提示，请点按“完成”（不要点按“移到废纸篓”）。这是未加入 Apple 付费计划的个人开发应用都会出现的提示，并非故障。

  4. 点按“仍要打开”

    点按屏幕左上角的苹果菜单 →“系统设置”→ 左侧列表中的“隐私与安全性”。在右侧向下滚动，会看到“DeltaShade”已被阻止以保护你的 Mac 的提示，点按“仍要打开”。如果再次询问，点按“仍要打开”，并用 Mac 的登录密码（或触控 ID）允许。此操作只需进行一次。

  5. 打开两项权限

    DeltaShade 打开后会出现“DeltaShade 权限”窗口。依次点按“屏幕录制”和“辅助功能”的“允许…”，在打开的系统设置列表中打开 DeltaShade 的开关（屏幕录制的项目名称为“录屏与系统录音”）。两项都打开后，点按“重新启动 DeltaShade”。

  6. 输入许可证密钥

    会打开“DeltaShade 许可证”窗口（如未打开，请点按屏幕右上角菜单栏中的 ΔE 图标 →“许可证…”）。选中邮件中的许可证密钥，按 ⌘（Command）+ C 复制，点按输入框后按 ⌘ + V 粘贴，然后点按“激活”。需要连接互联网。

  7. 设置自动启动（可选）

    点按 ΔE 图标 →“设置…”，打开“登录时打开 DeltaShade”，之后每次启动 Mac 时 DeltaShade 都会自动启动。

  8. 试用

    用“预览”等打开口内照片，把光标放在牙齿上，光标旁就会显示 L、a、b。在作为基准的牙齿上连按两次 Shift，再把光标移到要比较的牙齿上，就会显示 ΔE。

Windows

需要 Windows 11（64 位），无需管理员权限。

  1. 下载

    点击邮件中的 Windows 版下载按钮（DeltaShade-Setup.exe）。如果 Microsoft Edge 提示该文件“不常下载”，请点击该行的“…”→“保留”→“显示更多”→“仍然保留”。新应用可能会出现此提示。

  2. 打开安装程序

    在文件资源管理器中打开“下载”文件夹，双击 DeltaShade-Setup.exe。

  3. 点击“更多信息”→“仍要运行”

    如果出现蓝色的“Windows 已保护你的电脑”画面，请点击文中的“更多信息”，再点击下方出现的“仍要运行”。这是未加入 Microsoft 付费计划的个人开发应用会出现的提示，只在第一次出现。

  4. 安装

    如果出现选择语言的画面，请选择“English”并点击“OK”（安装程序只有英文和日文）。然后点击“Next”继续。勾选“Start DeltaShade when Windows starts”后，每次都会自动启动。点击“Install”→“Finish”后，DeltaShade 就会启动。

  5. 输入许可证密钥

    会打开“DeltaShade 许可证”窗口。选中邮件中的许可证密钥，按 Ctrl + C 复制，点击输入框后按 Ctrl + V 粘贴，然后点击“激活”。需要连接互联网。

  6. ΔE 图标在哪里

    DeltaShade 以 ΔE 图标的形式驻留在屏幕右下角（时钟附近）的通知区域。如果看不到，请点击“^”（显示隐藏的图标）。把图标拖到任务栏上，就能一直看到，十分方便。

  7. 试用

    用“照片”等打开口内照片，把光标放在牙齿上，光标旁就会显示 L、a、b。在作为基准的牙齿上连按两次 Shift，再把光标移到要比较的牙齿上，就会显示 ΔE。

遇到问题时

提示“已在 2 台电脑上使用”

1 个许可证密钥最多可用于 Mac 和 Windows 合计 2 台电脑。在不再使用的电脑上点按 ΔE 图标 →“许可证…”→“取消此电脑的激活”，即可在其他电脑上使用。如果旧电脑已损坏无法取消，请发邮件到下方地址联系我们。

没有收到购买邮件，或者弄丢了

请检查垃圾邮件文件夹。在 Lemon Squeezy 的“My Orders”中输入购买时的邮箱地址，通过收到的邮件中的链接即可再次查看下载和许可证密钥。

Mac 上不显示数值

可能是“屏幕录制”权限已关闭。请点按 ΔE 图标 →“权限…”，按照引导允许后重新启动 DeltaShade。换成新版本后，可能需要在系统设置中把 DeltaShade 的开关关闭后再重新打开。

在 Windows 上找不到 DeltaShade

在开始菜单中输入“DeltaShade”即可启动。即使正在运行，图标也可能藏在通知区域的“^”里。

想要卸载（删除）

先点按 ΔE 图标 →“许可证…”→“取消此电脑的激活”，许可证就能用在其他电脑上。Mac：把“应用程序”文件夹中的 DeltaShade 移到废纸篓。Windows：在“设置”→“应用”→“安装的应用”中，点击 DeltaShade 旁的“…”→“卸载”。

如果仍无法解决，欢迎联系我们（英语或日语）： support@deltashade.app
