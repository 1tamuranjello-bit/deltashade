Always in front

Click the photo — the values stay visible

Digital Color Meter is an ordinary window, so it disappears behind the photo as soon as you click the photo. DeltaShade's values are always right next to the cursor, on top of everything.

Digital Color Meter
  • Values appear in a separate window in a corner of the screen
  • Click to zoom or pan the photo, and it disappears behind
  • Every time you want to read a value, you find the window and bring it back
DeltaShade
  • Values appear right next to the cursor — no need to look away

Mac & Windows

Windows has no built-in tool to read screen colors in Lab

Every Mac comes with Digital Color Meter, but Windows has no equivalent. DeltaShade looks and works the same on Mac and Windows, with the same keys.

Mac

Digital Color Meter, made for comparing

The values are measured exactly like Digital Color Meter, plus an always-on display next to the cursor, ΔE from a reference and saved samples.

Windows

Lab and ΔE on Windows, with the same keys

Double-tap Shift for the reference, double-tap Ctrl for a sample — the same screens and keys as on the Mac. Lab is calculated from your display's color profile.

Install

Opening it for the first time

DeltaShade is made by an independent developer who is not enrolled in Apple's or Microsoft's paid developer programs. So the first time only, you need to confirm it as follows.

Mac

  1. Open the downloaded dmg and drag DeltaShade into the Applications folder.
  2. Double-click DeltaShade. If a message says it can't be opened, click “Done”.
  3. Open System Settings → Privacy & Security, scroll down and click “Open Anyway” next to DeltaShade.
  4. Follow the guide to allow Screen Recording and Accessibility.
  5. Open the ΔE icon in the menu bar and enter the license key from your email.

Windows

  1. Double-click the downloaded DeltaShade-Setup.exe.
  2. If you see “Windows protected your PC”, click “More info” → “Run anyway”.
  3. Follow the installer. No administrator rights are needed.
  4. Open the ΔE icon in the notification area and enter the license key from your email.

FAQ

FAQ

What are the Screen Recording and Accessibility permissions used for?

Screen Recording is used to read the color at the cursor, and Accessibility to detect the Shift and Control double-taps. Screen images are never saved or sent anywhere.

I see “Apple could not verify…” or “Windows protected your PC”. Is it safe?

This message appears for apps from independent developers who are not enrolled in Apple's or Microsoft's paid programs. Allow it once as described in “Opening it for the first time” above, and it will open normally from then on.

Do the values change if I change my monitor's color profile?

Like Digital Color Meter, DeltaShade converts back through the profile used for display, so in most cases they don't change. Only very saturated colors that the display can't show may change.

Can it measure the actual color in the mouth?

No. DeltaShade shows the colors recorded in the photo. It is not a substitute for a colorimeter and must not be used for diagnosis. Use it to compare photos taken under the same conditions.

Does it work on Intel Macs?

No. It requires a Mac with Apple silicon (M1 or later).

Are the values the same on Mac and Windows?

Both use the same formulas, but each OS handles screen color differently, so they are not exactly the same. In our tests the same color sample differed by about 0.7 or less. Always compare on the same computer.
