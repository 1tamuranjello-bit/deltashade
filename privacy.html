Owl Dental Create（以下「当方」）は、アプリ「DeltaShade」（以下「本アプリ」）および本ウェブサイトにおける個人情報の取り扱いについて、以下のとおり定めます。

1. 本アプリが扱う情報

  • 本アプリは、カーソル位置の色を計算するために画面の一部を読み取ります。読み取った画像はその場で色の計算にだけ使い、保存したり、外部に送信したりすることはありません。
  • キー操作は、Shift・Control の 2 度押しなど決められた操作を判定するためにだけ見張ります。入力した文字の内容を記録したり、送信したりすることはありません。
  • 保存した測定値や設定は、お使いのパソコンの中にだけ保存されます。

2. ライセンス認証で送信する情報

ライセンスキーを確認するため、本アプリはキーの入力時と定期的に、ライセンスキーと端末を区別するための名前を決済代行サービス Lemon Squeezy のサーバーに送信します。それ以外の情報は送信しません。

3. ご購入時の情報

ご購入時のお名前・メールアドレス・お支払い情報は、決済代行サービス Lemon Squeezy が受け取り、同社のプライバシーポリシーに従って管理されます。当方が受け取るのは、ご注文の内容とお名前・メールアドレスなど、サポートに必要な情報に限られます。クレジットカード番号を当方が受け取ることはありません。

4. 利用目的

  • ライセンスキーの発行と確認
  • お問い合わせへの回答、不具合の調査
  • アップデートなど重要なお知らせの送付

5. 第三者への提供

法令に基づく場合を除き、ご本人の同意なく個人情報を第三者に提供しません。

6. 本ウェブサイトについて

本ウェブサイトは GitHub Pages で公開しています。アクセス時の情報（IP アドレスなど）は GitHub 社が記録する場合があります。当方が独自にアクセス解析や Cookie による追跡を行うことはありません。

7. 開示・訂正・削除のご依頼

ご自身の情報の開示・訂正・削除をご希望の場合は、下記までご連絡ください。ご本人であることを確認したうえで対応します。
