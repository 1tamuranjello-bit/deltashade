Install guide

다운로드부터 사용 시작까지

구매 후 DeltaShade를 다운로드하고 설치해서 사용하기 시작할 때까지의 절차를 화면에 나오는 말 그대로 안내합니다. 컴퓨터에 익숙하지 않아도 위에서부터 차례로 따라 하면 됩니다.

먼저 구매 후 받은 이메일을 엽니다

구매가 끝나면 ‘Owl Dental Create’에서 구매 확인 이메일(영어일 수 있습니다)이 옵니다. 이 이메일에 다음 두 가지가 들어 있습니다.

  • 다운로드 버튼: Mac용(DeltaShade-….dmg)과 Windows용(DeltaShade-Setup.exe) 두 개. 사용하는 컴퓨터에 맞는 것만 있으면 됩니다.
  • 라이선스 키: ‘1A2B3C4D-…’ 같은 긴 영문·숫자 조합입니다. 앱을 사용할 수 있게 할 때 입력합니다.

이메일이 보이지 않으면 스팸 폴더도 확인하세요. 그래도 없으면 Lemon Squeezy ‘My Orders’에서 구매할 때의 이메일 주소를 입력하면 다운로드와 라이선스 키를 다시 확인할 수 있습니다.

Mac 절차로 Windows 절차로

Mac의 경우

M1 이후의 Apple 실리콘을 탑재한 Mac과 macOS 26 이상이 필요합니다.

  1. 다운로드하기

    이메일의 Mac용 다운로드 버튼(.dmg 파일)을 누릅니다. 파일은 ‘다운로드’ 폴더에 저장됩니다. Safari라면 오른쪽 위의 ↓ 버튼에서도 열 수 있습니다.

  2. ‘응용 프로그램’ 폴더에 넣기

    다운로드한 dmg를 더블 클릭하면 DeltaShade 아이콘과 ‘Applications’ 폴더가 나란히 있는 창이 열립니다. DeltaShade 아이콘을 ‘Applications’ 폴더 위로 드래그하세요. 끝나면 Finder 왼쪽의 ‘DeltaShade’ 옆 ⏏(추출)을 눌러 닫습니다.

  3. 처음 열기 (확인 창이 나옵니다)

    Finder의 ‘응용 프로그램’ 폴더에서 DeltaShade를 더블 클릭합니다. ‘DeltaShade’이(가) 열리지 않았다는 확인 창이 나오면 ‘완료’를 누르세요(‘휴지통으로 이동’은 누르지 마세요). Apple의 유료 개발자 등록을 하지 않은 개인 개발 앱에서 나오는 확인으로, 고장이 아닙니다.

  4. ‘그래도 열기’ 누르기

    화면 왼쪽 위의 Apple 메뉴 → ‘시스템 설정’ → 왼쪽 목록의 ‘개인정보 보호 및 보안’을 엽니다. 오른쪽을 아래까지 스크롤하면 Mac을 보호하기 위해 ‘DeltaShade’이(가) 차단되었다는 문구가 있으니 ‘그래도 열기’를 누릅니다. 다시 확인 창이 나오면 ‘그래도 열기’를 누르고 Mac 로그인 암호(또는 Touch ID)로 허용합니다. 이 조작은 처음 한 번뿐입니다.

  5. 두 가지 권한 켜기

    DeltaShade가 열리면 ‘DeltaShade 권한’ 창이 나옵니다. ‘화면 기록’과 ‘손쉬운 사용’의 ‘허용…’을 차례로 누르고, 열린 시스템 설정 목록에서 DeltaShade 스위치를 켭니다(화면 기록은 ‘화면 및 시스템 오디오 기록’이라는 항목입니다). 둘 다 켰으면 ‘DeltaShade 다시 시작’을 누르세요.

  6. 라이선스 키 입력하기

    ‘DeltaShade 라이선스’ 창이 열립니다(열리지 않으면 화면 오른쪽 위 메뉴 막대의 ΔE 아이콘 → ‘라이선스…’). 이메일의 라이선스 키를 선택해 ⌘(command) + C로 복사하고, 입력란을 클릭해 ⌘ + V로 붙여 넣은 뒤 ‘활성화’를 누릅니다. 인터넷에 연결되어 있어야 합니다.

  7. 자동으로 실행되게 하기 (선택)

    ΔE 아이콘 → ‘설정…’에서 ‘로그인 시 DeltaShade 열기’를 켜면 Mac을 켤 때마다 DeltaShade가 자동으로 실행됩니다.

  8. 사용해 보기

    미리보기 등에서 구강 내 사진을 열고 커서를 치아 위에 두면 커서 바로 옆에 L·a·b가 나옵니다. 기준으로 삼을 치아 위에서 Shift를 두 번 누르고, 비교할 치아로 커서를 옮기면 ΔE가 나옵니다.

Windows의 경우

Windows 11(64비트)이 필요합니다. 관리자 권한은 필요하지 않습니다.

  1. 다운로드하기

    이메일의 Windows용 다운로드 버튼(DeltaShade-Setup.exe)을 누릅니다. Microsoft Edge에서 ‘일반적으로 다운로드되지 않습니다’라고 나오면 그 줄의 ‘…’ → ‘유지’ → ‘자세히 표시’ → ‘그래도 계속’을 누르세요. 새로운 앱에서 나올 수 있는 표시입니다.

  2. 설치 프로그램 열기

    파일 탐색기의 ‘다운로드’ 폴더에 있는 DeltaShade-Setup.exe를 더블 클릭합니다.

  3. ‘추가 정보’ → ‘실행’ 누르기

    파란 화면에 ‘Windows의 PC 보호’가 나오면 글 속의 ‘추가 정보’를 누르고, 아래에 나오는 ‘실행’을 누릅니다. Microsoft의 유료 개발자 등록을 하지 않은 개인 개발 앱에서 나오는 확인으로, 처음 한 번뿐입니다.

  4. 설치하기

    언어를 고르는 화면이 나오면 ‘English’를 선택하고 ‘OK’를 누릅니다(설치 프로그램은 영어와 일본어만 지원합니다). 이후 ‘Next’로 진행합니다. ‘Start DeltaShade when Windows starts’에 체크하면 매번 자동으로 실행됩니다. ‘Install’ → ‘Finish’를 누르면 DeltaShade가 실행됩니다.

  5. 라이선스 키 입력하기

    ‘DeltaShade 라이선스’ 창이 열립니다. 이메일의 라이선스 키를 선택해 Ctrl + C로 복사하고, 입력란을 클릭해 Ctrl + V로 붙여 넣은 뒤 ‘활성화’를 누릅니다. 인터넷에 연결되어 있어야 합니다.

  6. ΔE 아이콘의 위치

    DeltaShade는 화면 오른쪽 아래(시계 근처) 알림 영역에 ΔE 아이콘으로 들어 있습니다. 보이지 않으면 ‘^’(숨겨진 아이콘 표시)를 누르세요. 아이콘을 작업 표시줄로 드래그해 두면 항상 보여서 편리합니다.

  7. 사용해 보기

    사진 앱 등에서 구강 내 사진을 열고 커서를 치아 위에 두면 커서 바로 옆에 L·a·b가 나옵니다. 기준으로 삼을 치아 위에서 Shift를 두 번 누르고, 비교할 치아로 커서를 옮기면 ΔE가 나옵니다.

문제 해결

‘이미 2대에서 사용 중입니다’라고 나옵니다

라이선스 키 하나로 쓸 수 있는 것은 Mac·Windows 합쳐 2대까지입니다. 더 이상 쓰지 않는 컴퓨터에서 ΔE 아이콘 → ‘라이선스…’ → ‘이 컴퓨터 등록 해제’를 누르면 다른 컴퓨터에서 쓸 수 있게 됩니다. 이전 컴퓨터가 고장 나 해제할 수 없다면 아래 이메일 주소로 연락해 주세요.

구매 이메일이 오지 않았거나 잃어버렸습니다

스팸 폴더를 확인하세요. Lemon Squeezy ‘My Orders’에서 구매할 때의 이메일 주소를 입력하면, 받은 이메일의 링크로 다운로드와 라이선스 키를 다시 확인할 수 있습니다.

Mac에서 수치가 나오지 않습니다

‘화면 기록’ 권한이 꺼져 있을 수 있습니다. ΔE 아이콘 → ‘권한…’을 열고 안내에 따라 허용한 뒤 DeltaShade를 다시 시작하세요. 새 버전으로 바꾼 뒤에는 시스템 설정에서 DeltaShade 스위치를 한 번 껐다가 다시 켜야 할 수도 있습니다.

Windows에서 DeltaShade가 보이지 않습니다

시작 메뉴에서 ‘DeltaShade’를 입력하면 실행할 수 있습니다. 실행 중이어도 아이콘이 알림 영역의 ‘^’ 안에 숨어 있을 수 있습니다.

제거(삭제)하고 싶습니다

먼저 ΔE 아이콘 → ‘라이선스…’ → ‘이 컴퓨터 등록 해제’를 눌러 두면 라이선스를 다른 컴퓨터에서 쓸 수 있습니다. Mac: ‘응용 프로그램’ 폴더의 DeltaShade를 휴지통에 넣습니다. Windows: ‘설정’ → ‘앱’ → ‘설치된 앱’에서 DeltaShade의 ‘…’ → ‘제거’를 누릅니다.

해결되지 않으면 편하게 문의하세요 (영어 또는 일본어): support@deltashade.app
