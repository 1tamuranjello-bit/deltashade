Always in front

点按照片，数值也不会被遮住

“数码测色计”是普通窗口，一点按照片窗口就会躲到后面。DeltaShade 的数值始终显示在光标旁边、所有窗口的最前面。

数码测色计
  • 数值显示在屏幕角落的单独窗口里
  • 为了缩放或移动照片而点按时，它会躲到后面
  • 每次看数值都要找到窗口并重新调到前面
DeltaShade
  • 数值显示在光标旁边，无需移开视线
  • 即使点按照片，也始终显示在最前面
  • 比较窗口也一直浮在前面，工作不会中断

Features

只做比色真正需要的事

一个不打扰平时所用的看图软件、只在旁边默默工作的小工具。

L* a* b*

始终显示在光标旁

每秒约 15 次读取光标下的颜色，并在光标旁边显示色块和 L、a、b。

ΔE00 / ΔE94 / ΔE76

与基准点的色差

设定基准点后，立即计算与光标位置的 ΔE。默认使用 CIEDE2000，也可在设置中切换为 CIE94 或 CIE76。

11 × 11 pt

与数码测色计相同的光圈

光圈大小为 1～11 共 6 档（默认最大）。以与 macOS 自带的数码测色计相同的方式，对相同范围取平均值。

Mac & Windows

Windows 没有用 Lab 查看屏幕颜色的自带工具

Mac 自带“数码测色计”，而 Windows 没有相应的自带工具。DeltaShade 在 Mac 和 Windows 上界面相同、按键操作相同。

Mac

把数码测色计变成比色工具

数值的测量方式与数码测色计完全相同，并增加了光标旁常驻显示、与基准点的 ΔE 以及比较点记录。

Windows

Windows 上也能用相同操作查看 Lab 和 ΔE

连按两次 Shift 设定基准点，连按两次 Ctrl 保存比较点，与 Mac 版界面和操作相同。会读取显示器的颜色描述文件来计算 Lab。

Install

首次打开时的步骤

DeltaShade 由个人开发，没有加入 Apple 或 Microsoft 的付费开发者计划。因此仅在首次打开时，需要在确认画面中进行以下操作。

Mac

  1. 打开下载的 dmg，把 DeltaShade 拖到“应用程序”文件夹。
  2. 连按 DeltaShade。如果出现无法打开的提示，请点按“完成”。
  3. 打开“系统设置”→“隐私与安全性”，在下方 DeltaShade 旁点按“仍要打开”。
  4. 按照引导允许“屏幕录制”和“辅助功能”。
  5. 打开菜单栏中的 ΔE 图标，输入邮件中的许可证密钥。

Windows

  1. 双击下载的 DeltaShade-Setup.exe。
  2. 如果出现“Windows 已保护你的电脑”，请点击“更多信息”→“仍要运行”。
  3. 按照画面引导完成安装，无需管理员权限。
  4. 打开通知区域中的 ΔE 图标，输入邮件中的许可证密钥。

FAQ

常见问题

屏幕录制和辅助功能权限用来做什么？

屏幕录制用于读取光标位置的颜色，辅助功能用于检测连按两次 Shift、Control。不会保存屏幕图像，也不会发送到外部。

出现“Apple 无法验证…”或“Windows 已保护你的电脑”，安全吗？

未加入 Apple 或 Microsoft 付费开发者计划的个人开发应用会出现此提示。按照上面“首次打开时的步骤”允许一次，之后即可正常启动。

更改显示器的颜色描述文件后，数值会变吗？

与数码测色计一样，会通过显示所用的描述文件反算，因此大多数情况下不会变。只有显示器无法显示的非常鲜艳的颜色可能会变。

能测量口腔内的真实颜色吗？

不能。DeltaShade 显示的是照片中记录的颜色，不能代替测色仪，也不能用于诊断。请用于比较拍摄条件一致的照片。

能在 Intel Mac 上使用吗？

不能。需要搭载 Apple 芯片（M1 及更新）的 Mac。

Mac 和 Windows 上的数值相同吗？

两者使用相同的公式计算，但各操作系统处理屏幕颜色的方式不同，因此不会完全相同。开发期间的测试中，同一色样的差异约在 0.7 以内。请始终在同一台电脑上进行比较。
